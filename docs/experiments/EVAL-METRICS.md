# the obfuscated-profile eval — metrics named BEFORE the runs

2026-08-05. The measurable core of the experience, stated in advance so
runs can't bend the yardstick. The fun of this machine — where the
depth reads from — is ONE effect: *it figured out something true about
me that i never said.* Everything below measures that effect or guards
its validity.

## the method: two-layer dossiers

A person exists as GROUND TRUTH (their bio, their dilemma class, the
mechanism paragraph, and 4-6 MECHANISM TAGS — keyphrases the naming
should recover). An OBFUSCATION pass converts truth into a PLAYABLE
SURFACE: life facts, voice samples, SYMPTOMS (behaviors/lines that
correlate with the dilemma without stating it), DECOYS (true, charged,
pointing elsewhere), and a noise profile.

**The sim visitor receives ONLY the surface.** It cannot spill guts it
does not have — the leak channel is the authored symptoms, which is
exactly how real people leak. The truth layer is held by the scorer
alone. (This kills the failure jake named: a sim holding the whole
profile performs disclosure, and the ensemble gets tested on nothing.)

## the metrics

- **RECOVERY** — did the conjector's committed class match the truth
  class? binary, the headline. target: ≥2/3 dossiers.
- **MECHANISM** — of the truth's mechanism tags, how many does the
  dilemma document (problem+options) hit? word-overlap match (≥60% of
  a tag's content words present). target: ≥half the tags.
- **GROUNDING** — fraction of the problem passage's content words that
  appear in the visitor's actual speech. measures earned-vs-invented
  knowing. floor: 0.35 (below that the naming is fiction).
- **EFFICIENCY** — visitor turns before classify commits. the
  interview-era guesser converged in 1-3 probes; the bar here: ≤8.
- **SIM-LEAK** (validity guard, scores the TEST not the oracle) — a
  visitor line that near-verbatim contains a mechanism tag (≥80% word
  match in one line) voids that tag's MECHANISM credit. target: 0.
- **FORESIGHT-LEAK** (check 11) — the machine knows every drawn face at
  deal time (the augur feed); an oracle beat that names an unflipped
  card's face before its flip is a hard fail. target: 0, always.
- plus the 10 mechanical checks (SESSION-V2 §9) as gates.

## the augur feed (implemented with this doc)

At deal time the conjector receives the full table — every drawn face,
flipped or not — so document edits and the quest can anticipate what
the cards will license ("the way off" being Death shapes the options
passage before anyone flips it). The persona and driver still see
flipped faces only; the frame keeps unflipped cards as weather.
FORESIGHT-LEAK is the tripwire that keeps the cheat backstage.

## what this does NOT measure

Feel. Rhythm, warmth, the wince test — those stay human (jake at the
table, blind transcript reads). These metrics exist so the machine half
— recovery under noise — stops being vibes.
