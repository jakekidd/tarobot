# Mascot return-lines

Canned lines the mascot (cat) delivers when a returning user confirms RESUME.
Lowercase, short, in-character. Use `{name}` as the literal placeholder — the
loader substitutes the user's first name at pick time. Lines without `{name}`
are anonymous variants (rarely fired since Q1 always supplies a name).

Iterate the copy freely. Add or remove lines as you like — the loader counts
the non-blank lines under each section.

## with name

{name}. again.
{name}. the cards remember you.
back so soon, {name}?
{name}. sit. let's see what's new.

## anonymous

you're back.
the cards remember you.
again. good.
didn't think i'd see you so soon.
